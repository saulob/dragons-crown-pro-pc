# Comms Wheel icons

Temporary placeholder icons for the Comms Wheel, to be replaced or cleaned up later. All come from SVG Repo
(www.svgrepo.com) and need no attribution; licences were read from each icon's page on 2026-11-19. Files are renamed
from `<name>-svgrepo-com.svg`; only line endings and trailing spaces were normalized. They are used only as silhouettes: `icons.png` is every icon
rendered white on transparent in message id order (4 columns by 2 rows of 128 px cells) by `scripts/comms_icon_atlas.py`
(needs rsvg-convert), and the overlay tints it.
